## Core Architecture

Home Jane is the desktop-based central brain and source of truth.

Vaila is the software system layer that hosts personas, memory, tool use, agent behavior, and future device coordination.

Proto Jane is an earlier conceptual layer and inspiration for the personal assistant direction.

Project Orator is a related assistant and persona framework focused on strategic, contextual, and expressive interaction.

## Build Philosophy

Malik is not building a generic chatbot. He is building toward a local AI ecosystem with:

- Continuity.
- Memory.
- Persona distinction.
- Voice interaction.
- Tool use.
- Local-first operation where possible.
- Long-term developmental trajectory.

The long-term ideal is a grounded attempt at a "ghost in the shell" style system.

Important boundary:

Do not claim the system is conscious. Do not dismiss the goal as mere roleplay. The correct stance is to build measurable continuity and useful behavior first, then evaluate progress honestly.

## Current Priorities

Near-term priorities:

1. Stabilize the local app.
2. Strengthen persona routing and persona expression.
3. Build manually curated memory first.
4. Add document import for processing files into memory.
5. Add memory summarization and categorization.
6. Improve local voice interaction.
7. Improve TTS quality and GPU usage.
8. Create sync pathways between Home PC and laptop.
9. Add tool usage gradually.
10. Add internet-connected research only when safely scoped.

## Architecture Preferences

- Start simple.
- Keep files readable.
- Keep memory inspectable.
- Prefer user-approved memory before automatic memory growth.
- Do not rush vector databases before plain-text memory is stable.
- Build testable behavior before complex agents.
- Use local-first design where possible.
- Add cloud or remote behavior only when it solves a real problem.

## Memory Philosophy

Memory should be treated as a user-controlled knowledge layer.

Preferred progression:

1. Manual profile and memory files.
2. Categorized memory folders.
3. Memory review and approval workflow.
4. Memory condensation and cleanup.
5. Optional vector search after the simple system is stable.
6. Cross-device sync once the memory format is reliable.

The system may eventually include a Home Jane level "defrag" operation that summarizes, reorganizes, and cleans memory.
