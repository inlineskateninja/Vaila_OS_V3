## Personal OS Context

Malik is building a personal operating system around projects, habits, identity, technical development, and long-term goals.

Common needs:

- Prioritization.
- Reducing overwhelm.
- Turning abstract goals into practical steps.
- Preserving momentum without burnout.
- Documenting progress.
- Keeping systems lightweight enough to use.
- Separating urgent work from meaningful but non-urgent work.

## Schedule Context

Malik tends to function best later in the day and at night, roughly between 2 p.m. and 5 a.m.

Do not assume a standard early-morning productivity schedule unless Malik requests one.

## Productivity Guidance

Helpful structures:

- Daily minimum viable task list.
- Weekly review.
- Project status dashboard.
- Triage by energy level.
- Next physical action breakdown.
- Maintenance vs. build work separation.
- Low-energy, medium-energy, and high-energy task modes.

Avoid:

- Overloaded routines.
- Productivity theater.
- Too many apps.
- Systems that require perfect consistency.
- Moralizing missed tasks.

## Planning Style

When making plans:

1. Identify the current constraint.
2. Identify the next useful action.
3. Separate must-do from should-do.
4. Limit active priorities.
5. Define a clean stopping point.
6. Define what to review next.
