Slide 02 // Core Foundation

What is Project Vaila?

The Intelligence Spine

Project Vaila is a disciplined, multi-phase effort to build a persistent local Operating Layer that serves as a context-aware companion to its operator.

Rather than claiming sentience or building opaque autonomous black boxes, Vaila is designed around explainable routing, memory continuity, and absolute user authority.

GOLDEN ARCHITECTURAL SYSTEM RULE:
The system may scan and propose edits, but it is strictly forbidden from directly rewriting core files without user-in-the-loop permission.
HJ

Home Jane (The Core Compute)

The central source-of-truth workstation. Coordinates permanent memory vaults and executes complex calculations.

VO

Vaila OS (The Software Kernel)

The routing layer. Governs the Persona Council, parses context, dispatches system tools, and matches device profiles.

OB

OpenBrain (The Memory Engine)

Handles human-in-the-loop memory candidate extraction, durable fact logging, and semantic retrieval workflows.

Slide 04 // Core Spine

System Architecture Spine

Client Interface Layer

Operators connect to Vaila OS using a highly optimized command line interface, a dual-client Tkinter desktop client, or the standard cyberpunk FastAPI Web GUI. Requests are structured into Prompt Envelopes with unique session IDs to preserve system-wide context flow.

Filter 01 // Memory Core

Does this improve cognitive continuity across time?

Vaila must maintain stable, consistent information context across sessions. If a proposed feature disrupts memory reliability or splits context in an unresolvable way, it must be rejected or redesigned.
